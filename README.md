# GLB Print Prep

**Fix GLB files that won't open, then shrink them for 3D printing — with the deviation measured, not guessed.**

GLB Print Prep is a native macOS app (and a cross-platform command-line tool) for people who print models
generated by AI tools such as Tripo, Meshy or Hunyuan3D, or downloaded from the web:

- **Repair** — many generators ship GLBs compressed with `EXT_meshopt_compression`, `KHR_mesh_quantization`
  or Draco. Blender, most slicers and many viewers can't open them ("Invalid byteLength", empty scenes,
  import errors). GLB Print Prep decompresses them into a standard GLB and **proves** the result is identical
  to the original before touching anything.
- **Optimize for printing** — AI models often have 1–2 million triangles, far more than an FDM or resin
  printer can reproduce. GLB Print Prep finds the **fewest triangles whose measured deviation from the
  original surface stays below what your printer can resolve** (e.g. 0.02 mm for a 0.2 mm nozzle and
  0.08 mm layers), at the real printed size.

## Features

- Drag & drop files or whole folders (subfolders included), batch processing in parallel on Apple Silicon
- Five independent checks before an original is moved to the Trash (never deleted — always restorable):
  1. consistent GLB container, no compression extensions left
  2. opens with a plain glTF reader (no decoders)
  3. 0 errors from the official Khronos glTF validator
  4. identical content: every vertex attribute, index, material, node transform and texture (SHA-256)
  5. written to disk atomically and read back with a matching checksum
- Print optimization with a **tolerance in millimetres** derived from nozzle and layer height, detection of
  the round base to get the real scale (25/28/32/40/50/60 mm presets), symmetric Hausdorff distance
  measurement, and topology checks (no new holes or non-manifold edges)
- Live progress: current step, elapsed time, ETA, CPU/RAM heartbeat of the engine
- Rotating 3D thumbnails and a full RealityKit viewer (PBR materials, WebP textures, point clouds)
- Optional "keep only optimized versions" mode that trashes the intermediate files
- Liquid Glass design for macOS 26+

## Install

### macOS app

1. Download `GLB-Print-Prep-x.y.z-macOS-arm64.zip` from the [latest release](https://github.com/Camponotus-vagus/glb-print-prep/releases/latest).
2. Unzip it and move **GLB Print Prep.app** to Applications.
3. The app is not notarized yet, so the first time **right-click → Open** (or run
   `xattr -dr com.apple.quarantine "/Applications/GLB Print Prep.app"`).

Requires macOS 26 or later on Apple Silicon. Node.js is bundled — nothing else to install.

### Command line (macOS, Linux, Windows)

Requires Node.js 22 or later.

```sh
git clone https://github.com/Camponotus-vagus/glb-print-prep.git
cd glb-print-prep/engine && npm ci
node bin/glb-print-prep.mjs --help
```

## Usage (CLI)

```sh
# Repair: model_meshopt.glb → model.glb (or model_fixed.glb). Inputs are never modified.
glb-print-prep model_meshopt.glb other.glb

# Optimize for a 32 mm base, 0.2 mm nozzle, 0.08 mm layers, "high" detail (0.02 mm tolerance)
glb-print-prep --optimize --base 32 model.glb

# Explicit tolerance, or another printer profile
glb-print-prep --optimize --base 25 --tolerance 0.01 model.glb
glb-print-prep --optimize --nozzle 0.4 --layer 0.12 --detail medium model.glb

# Fixed triangle budget (no tolerance)
glb-print-prep --target 300000 model.glb
```

| Detail level | Tolerance                     | 0.2 mm nozzle / 0.08 mm layer |
| ------------ | ----------------------------- | ----------------------------- |
| extra-high   | min(layer / 8, nozzle / 20)   | 0.01 mm                       |
| high         | min(layer / 4, nozzle / 10)   | 0.02 mm                       |
| medium       | min(layer / 2, nozzle / 5)    | 0.04 mm                       |
| low          | min(layer, nozzle × 2/5)      | 0.08 mm                       |

`--json` emits one NDJSON progress event per line (this is how the app talks to the engine).
Exit codes: `0` success, `1` at least one file failed, `2` usage error.

## How it works

Repair uses [glTF-Transform](https://gltf-transform.dev) with the meshoptimizer and Draco decoders, then
verifies the output against the decoded original. Optimization uses meshoptimizer's attribute-aware
quadric simplifier, removes zero-thickness "fins", protects against pinched non-manifold edges, and runs a
bracketing search on the triangle count until the measured Hausdorff deviation lands just under the
tolerance. Details: [docs/how-it-works.md](docs/how-it-works.md).

### Compared with slicer simplification

On a 1.89 M-triangle miniature (18.9 mm base), Bambu Studio's "Extra high" simplification kept
133,529 triangles, with no measurement of the resulting error. GLB Print Prep kept **124,037 triangles
with a measured maximum deviation of 0.018 mm** (tolerance 0.02 mm), no holes and no non-manifold edges.
More in [docs/benchmarks.md](docs/benchmarks.md).

## Limitations

- The app needs macOS 26+ on Apple Silicon; the CLI runs anywhere Node.js 22+ runs.
- Base detection assumes the model stands upright (Y-up, as glTF specifies); when no round base is found,
  the largest horizontal extent is taken as the base size.
- Only triangle meshes are simplified; point clouds and lines are left as they are.
- The macOS app is not notarized yet (see Install).
